# 🎰 Fizz Buzz Combo API

ギャンブル性と戦略性を兼ね備えた、シングルプレイのシンプルなスコアアタックゲームです。
ユーザーのスコアは、各ゲームごとにランダムに生成される数字(デフォルトで1~100の間)とゲーム開始前に選ぶスコアを決める複数の**ルール**によって計算されます。

例えば、生成された数字が3の倍数の時に3ポイント得られる**Fizz**ルールや5の倍数の時に5ポイント得られる**Buzz**ルールなどがあります。

## 🚀 主な機能

* **ルール**のリストの表示
* 選択した**ルール**のidのリストを使って、ゲームプレイ
* ランキングの表示(個人またはグローバル)

## 🛠 技術スタック

* **Language:** Java 21
* **Framework:** Spring Boot 4.1
* **Database:** H2 (Dev) / PostgreSQL (Production)
* **ORM:** Spring Data JPA (Hibernate)
* **Migration:** Flyway

## 📁 プロジェクト構成
```
src/main/java/com/example/fizzbuzz
├── controller/        # APIの入り口（Controller Adviceもここ）
├── service/           # スコア計算、ランキング、ルールのロジック
│   └── gamerule/      # 各ゲームルールやインターフェースの実装
├── repository/        # DBアクセス（Spring Data JPA）
├── entity/            # DBテーブルの定義
└── config/            # 設定プロパティやセキュリティ設定
```

## 💡 こだわった設計ポイント

### 1. コレクション注入を使ったルールの拡張性
SRP原則,OCP原則に基づき、Spring Bootのコレクション注入機能を使って、ゲームルールの非常に高い拡張性と単一責任性を実現しました。(ルールを追加する際は、インターフェースを実現したクラスを追加し、その初期データをデータベースに加えるだけです。)

### 2. Stream APIを使った、宣言的なスコア計算サービス
ゲームルールのインターフェースに持たせた、shouldApply述語やスコアやコンボの倍率を取得するgetScore,getMultiplierをStream APIで回すことで、宣言的にスコアの計算を行っています。

### 3. 設定プロパティを用いたゲームパラメータの変更容易性
各ゲームルールのスコアやコンボの倍率などはすべて、設定プロパティとして切り出しており、パラメータ調整が容易です。
